基于 Epoll 边缘触发（ET）事件循环、固定线程池、有限状态机解析与内存映射零拷贝响应构建，兼顾低延迟与连接复用。

I/O 多路复用
Epoll ET

采用 EPOLLET + EPOLLONESHOT 边缘触发与非阻塞套接字，单线程高效分发高并发就绪事件。

并发调度
4 Workers

内置 ThreadPool 任务队列，将 HTTP 解析、数据库校验与响应写回解耦至工作线程执行。

连接复用与超时
Keep-Alive

默认启用 HTTP/1.1 长连接复用，配合 10 秒小根堆定时器（TimerNode）自动清理空闲连接。

协议解析与零拷贝传输

有限状态机 + Mmap / Writev

HttpParser 按请求行、请求头、消息体四态循环解析粘包请求；静态 HTML 通过 mmap 内存映射与 writev 集中写直接发送。

安全认证与可观测性

MySQL 连接池 + 异步日志

SqlConnPool 配合 RAII 句柄与 MYSQL_STMT 预处理防注入，密码经加盐 SHA-256 校验；AsyncLogger 双缓冲异步写入 server.log。
